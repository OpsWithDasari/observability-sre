# Observability & Site Reliability Engineering (SRE)

A comprehensive hands-on learning repository covering **Observability, Monitoring, Logging, Distributed Tracing, and Site Reliability Engineering (SRE)**. Learn how to monitor applications and infrastructure, identify performance issues, troubleshoot production incidents, and improve system reliability and availability.

Explore industry-standard tools and technologies such as **Prometheus, Grafana, Alertmanager, ELK Stack, OpenSearch, Loki, Jaeger, OpenTelemetry, and Datadog** through practical examples, configuration files, dashboards, automation scripts, and real-world projects.

This repository covers key SRE concepts, including Service Level Indicators (SLIs), Service Level Objectives (SLOs), Service Level Agreements (SLAs), error budgets, incident management, root cause analysis, capacity planning, and performance optimization.

Designed for beginners and experienced DevOps engineers who want to build reliable, scalable, highly available, and observable systems.

## Learning Objectives

By working through this repository, you will learn how to:

- Monitor infrastructure, applications, and Kubernetes clusters.
- Collect and analyze metrics, logs, and distributed traces.
- Build interactive monitoring dashboards.
- Configure alerts and notifications.
- Identify and troubleshoot production issues.
- Implement SRE practices and reliability standards.
- Improve application performance and system availability.
- Build end-to-end observability solutions for production environments.

**Goal:** Build strong practical knowledge of Observability and SRE to monitor, troubleshoot, and maintain reliable production systems.
